# 小丑牌 Web V1.0.0

基于扑克牌型的单机数值小游戏，Balatro-like 核心引擎的 Web 实现。选 1–5 张牌组成牌型，限 4 次出牌内累计超过 300 分即胜。

## 游戏规则

- 标准 52 张牌，每局随机洗牌，初始发 8 张手牌
- 出牌机会 4 次，弃牌机会 3 次，目标 300 分
- 10 种牌型识别（高牌 → 皇家同花顺），计分公式：`(基础分 + 选中牌点数之和) × 倍数`
- 累计分 ≥ 300 胜利；出牌耗尽且分不足失败

## 安装 & 运行

无需任何依赖，直接双击打开：

```bash
open game.html
```

或在浏览器地址栏输入文件路径即可。

## 文件说明

| 文件 | 说明 |
|------|------|
| `game.html` | 游戏主文件，单文件包含全部逻辑和样式 |
| `PRD.html` | 产品需求文档 |
| `DESIGN.html` | 视觉设计规范（Design Tokens、组件状态） |
| `agents/` | Claude Code 自定义 Agent 角色定义 |
| `slash/` | Claude Code 自定义斜杠命令 |
